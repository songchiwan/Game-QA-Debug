# 1. BUG-01 : 게임 이벤트 메세지 발생 오류
심각도 : 상

단계 재현 :
1. 스토리 진행 중에는 점검 메세지를 제외한 나머지 이벤트 메세지는 발동되면 안됨.
2. 스토리 파트 넘어가는 과정에서 이벤트 메세지 발생

예상 결과 : 스토리 파트가 완전히 다 끝난 후에 이벤트 메세지가 발생했어야함.

실제 결과 : 나뉘어진 스토리 파트끼리 넘어가는 과정에서 이벤트 메세지가 발생하고 컨트롤러 조작 불가 상태에 빠졌었음. 상황 해제하는 행동으로 인해 스토리 대사를 넘길 수 있었음. 즉 이벤트 페이지와 스토리 상태가 동시에 적용된 것임.

스크린샷/로그 : [유튜브 링크](https://youtu.be/zHA0-edzSoU)

# 2. BUG-02 : 게임 진행 오류
심각도 : 상

단계 재현 :
1. 대사 클릭 

예상 결과 : 대사 클릭 후 다음 메세지 또는 스토리가 진행됐어야함. 

실제 결과 : 대사를 여러 번 클릭해도 다음 대사 또는 다음 장면으로 넘어가지 않음. 재접속을 해야 진행이 됐었음.

스크린샷/로그 : [유튜브 링크](https://youtu.be/sGIqWgLONBY)
