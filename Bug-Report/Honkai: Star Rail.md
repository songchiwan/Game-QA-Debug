# 1. BUG-01 : 게임 이벤트 메세지 발생 오류
심각도 : 상

단계 재현 :
1. 스토리 진행 중에는 점검 메세지를 제외한 나머지 이벤트 메세지는 발동되면 안됨.
2. 전투가 끝난 후 게임 내 이벤트 메세지 단체 전송이 됨. 

예상 결과 : 전투도 스토리 파트로 포함을 시켜야 하고 스토리 파트가 끝난 후에 이벤트 메세지가 발생했어야함.

실제 결과 : 1차 전투 이후 스토리 진행 중에 이벤트 메세지가 발생함.

# 2. BUG-02 : 게임 진행 오류
심각도 : 상

단계 재현 :
1. 대사 클릭 

예상 결과 : 대사 클릭 후 다음 메세지 또는 스토리가 진행됐어야함. 

실제 결과 : 대사를 여러 번 클릭해도 다음 대사 또는 다음 장면으로 넘어가지 않음.
