# 1. BUG-01 : 메인 스토리, 캐릭터 뽑기 대사 사운드 누락
심각도 : 상

단계 재현 :
1. 로그인/계정 생성 후 로그인 시 스토리를 볼 경우 대사 사운드가 들려야함
2. 스토리 진행 중 클릭
3. 뽑기 중엔 캐릭터 대사 재생

예상결과 : 메인 스토리 파트 구간 중 대사가 있는 경우 대사가 재생되야 함. 뽑기 하는 중에는 캐릭터 각각 대사가 재생되어야 함. 

실제결과 : 영상 구간은 정상적으로 나왔지만 스토리 구간과 캐릭터 뽑기의 모든 대사가 사운드 누락됨.
